# Toolhub Naiyo

A modern, fast, and feature-rich web application built with React, Vite, and Tailwind CSS. Toolhub Naiyo offers a suite of handy tools ranging from educational utilities (like an Assignment Planner and Number Base Converter) to everyday productivity helpers (like Case Converter, BMI Calculator, and Image/PDF utilities).

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🛠️ Getting Started

### Prerequisites

Make sure you have Node.js and your preferred package manager (`npm`, `yarn`, `pnpm`, or `bun`) installed.

### Installation

1. Navigate to the project directory:
   ```bash
   cd Toolhub_Naiyo_Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application. The page will automatically reload if you make edits.

### Building for Production

To create an optimized production build:

```bash
npm run build
```

You can preview the production build locally with:

```bash
npm run preview
```

## 📁 Project Structure

The codebase is organized as follows:
- `src/components/`: Reusable React components.
  - `tools/`: Specific tool components (e.g., AssignmentPlanner, CaseConverter).
  - `ui/`: Common UI elements.
  - `layout/`: App layout components (Navbar, Footer).
- `src/pages/`: Page-level components corresponding to different routes.
- `src/data/`: Static data and configurations.
